# scrcpy 无线投屏

日常使用只有一个入口：双击 `启动投屏.bat`。已有桌面“无线投屏-开始使用”快捷方式可继续使用，无需选择画质档位。

统一默认设置为最长边 **1600、H.264、6Mbps、最高 60fps**，电脑自动使用硬件解码并保留软件回退，视频不增加播放缓冲。静态画面帧率会自动降低，属于正常行为。

手机和电脑需处于可互访的网络，手机开启无线调试。首次按提示配对，之后自动确认原手机并寻找可用连接。重复点击启动不会多开；关闭投屏窗口结束，连接等待时在控制台按 Ctrl+C 结束。保留手机原有锁屏和解锁方式。

## 安装

Windows 64 位 PowerShell，在项目目录运行：

```powershell
& .\setup.ps1
& '.\启动投屏.bat'
```

脚本下载固定版本 scrcpy 5.0.1 与 Python 3.13.14 嵌入环境，验证官方发布摘要后放入 `tools/scrcpy` 与 `runtime/python`。该中继绑定 scrcpy 5.0.1 协议，升级时需一起验证控制协议。

已有完整便携目录可复用依赖：

```powershell
& .\setup.ps1 -LocalSource 'D:\Tools\scrcpy'
& .\setup.ps1 -VerifyOnly
```

复用只复制运行依赖，不导入设备记录、日志或备份。

## 断线恢复

- 优先使用已经在线的 mDNS 连接通道，并核对设备身份；新广播端口优先于缓存中的旧端口。
- 视频或控制流结束会通知监控器重建连接。单次 ADB 检查失败会复查，视频仍在传输时保留当前窗口。
- 掉线后持续自动等待原手机，连续失败会逐步放慢重试，最长单次退避 15 秒；不会三次失败就退出，也不会一分钟后停止自动发现、等待输入。
- 启动时控制通道超过 15 秒未建立会重试。正常关闭窗口会退出，清理其所属连接，不会自动重新打开。

无线调试被关闭、授权被撤销或网络长期不可用时，仍需在手机恢复相应设置；程序继续等待，授权变更需要重新配对。更多依据和验证范围见 [画质与连接说明](docs/latency.md)。

## 维护

日常无需执行以下命令，均通过同一个启动文件进入：

```powershell
& '.\启动投屏.bat' pair        # 重新配对
& '.\启动投屏.bat' --check     # 只检查依赖和连接
& '.\启动投屏.bat' --diagnose  # 只采样 ADB 命令往返
```

`--diagnose` 记录 8 次命令往返的中位数、P95 和失败数，写入本机 `data/latency-diagnostics.json`。数值包含命令启动开销，**不是画面或触控端到端延迟**，不记录设备地址与序列号。`--stats` 可临时记录帧率；其他维护参数见 `--help`。

## 目录与测试

- `app/`：启动器和控制中继；`tests/`：模拟设备及本机回环传输测试。
- `docs/`：实现说明、依赖摘要及历史验证记录。历史记录不代表本版实机测试。
- `data/`：本机设备缓存和日志；`backup/`：本机历史备份，均不上传。
- `tools/scrcpy/`、`runtime/python/`：初始化生成的依赖，不进入版本控制。

Python 3.10 或更新版本运行：

```powershell
python -X utf8 -B tests/test_mirror.py
```

71 项测试覆盖设备身份、配对、端口变化、断线重试、亮熄屏、单实例、窗口关闭和控制消息分帧。回环测试验证 3MiB 视频字节完整转发、半断开通知、空闲连接和退出清理；测试不连接实体手机。
