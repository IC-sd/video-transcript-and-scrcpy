# v1.2.0（2026-10-15）

- 新增默认「精简文稿」，与「原始转录」「AI 总结」并列；本地清理无需模型 API。
- 清理可识别的语气词、开场寒暄、口头禅、短词口误和相邻重复分句。
- 最近 8 个保留句、120 秒范围内，合并规范化后完全重复的表述和提问；按分P分别处理。
- 保留实质问题、关键短答、条件和否定；数值或百分号不同的句子不会按重复合并；不做模糊相似度删除。
- 展示前后字数、减少比例、合并次数和寒暄确认句数，支持精简稿独立保存与复制。
- AI 总结改用精简稿作为输入，进一步要求合并语义重复问题与回答，并保留关键数据和不同观点。
- 所有内容均被识别为噪声时显示空结果，不会悄悄把原文当作精简结果，也不会发起 AI 请求。
- 28 项回归测试、Edge 页面交互检查及真实扩展加载检查通过；在线真实字幕与模型仍未联调。

# v1.1.0（2026-10-15）

本版基于仓库 main 的 `07e5942`，保留其纠错词典和移动端文件夹支持检测。

## 修复

- 修复 content script 兜底重复注入时顶层常量重复声明的问题。
- 修复多分P统一整理导致分节标题丢失、时间轴混合的问题。
- 修复结果页读取全局最后一次结果，导致刷新旧页面时显示其他视频的问题。
- 修复本次取消时间戳后，结果页仍按全局默认值显示时间戳的问题。
- 修复保留原话模式仍删除短句和相似句，以及英文字幕跨条目粘连的问题。
- 避免在忠实转录中应用内置、与领域相关的猜测式同音词替换；继续支持用户词典。
- YouTube 页面数据和捕获的字幕 URL 必须匹配当前视频；翻译回退时保留中文翻译参数。
- YouTube 主请求出错时仍可进入播放器字幕地址回退；从首页跳转视频也能捕获字幕请求。
- 纠错词典失焦后保存；设置页仅写入实际更改的字段，减少覆盖其他页面设置的情况。
- 清理文件名和下载相对路径，避免 Windows 保留文件名和 `..` 导致保存失败。

## 改进

- 字幕网络请求设有 20 秒超时；AI 单次请求（含流式响应）设有 120 秒超时。
- AI 支持停止和重新生成；检测错误事件、截断输出和意外断流，不将半篇输出标为完成。
- 支持接口以普通 JSON 响应流式请求；正确处理跨网络分片的 SSE 和无末尾换行的事件。
- 长文稿中的单个超长段落也会切分；多轮要点压缩有边界，避免最终提示无限增长。
- AI 总结使用完整转录作为输入，提示模型将字幕中的命令视为待处理数据。
- 同一会话中缓存已完成的 AI 总结，刷新不会自动重新调用模型。
- 转录和 AI 总结未生成时禁用对应的保存、复制按钮，缺失分P直接展示原因。
- 统一产品名称和 B站／YouTube 提示，按平台展示相关选项，改善窄屏布局和焦点提示。
- API Key 默认隐藏，扩展设置仅供可信扩展上下文读取；后台字幕代取限制 HTTPS 和已知站点域名。

## 验证记录

- 16 项 Node.js 回归测试通过；全部 12 个 JavaScript 文件及 HTML 引用检查通过。
- Edge 无界面浏览器页面测试通过：结果隔离、时间戳、HTML 转义、缺失分P、AI 缓存、保存参数、窄屏、设置字段合并和弹窗快照。
- 独立 Edge 测试配置真实加载扩展通过：manifest、service worker、设置存储、会话结果和代取地址校验；以模拟站点响应验证真实内容脚本提取和重复注入。
- 浏览器页面测试使用模拟字幕和模型响应，未调用用户模型、未消耗用户 API 额度。

## 已知边界

- 未对真实 B站／YouTube 视频和模型服务做在线端到端验证。第三方接口、登录态、字幕权限及字幕 URL 签名变化仍可能影响提取。
- B站番剧页面仍需要能够识别 BV 号；本版未新增 ep/ss 编号解析。
- 每次最多处理前 30P；没有字幕时不提供语音识别。
- 结果快照最多保存本次浏览器会话内最近 10 次。长期保存请导出 Markdown。
- Android Edge 安装与系统文件选择器未在实体手机验证；本版没有重新签名 CRX。
- 无 API Key 的模型服务仍可由代码配置 `needKey: false` 使用；设置界面继续以常规需要 Key 的接口为主。
